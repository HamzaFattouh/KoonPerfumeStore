# متجر كون بيرفيوم | KOON PERFUME
### الفخامة في أبعاد كوكبية مستوحاة من سحر وأسرار الكون

متجر إلكتروني متكامل للواجهة الأمامية (Frontend) لعلامة العطور الفاخرة **"كون بيرفيوم" (KOON PERFUME)** مبني بأحدث تقنيات **React.js**، **Vite**، و **Tailwind CSS**.

---

## 🌟 مميزات المشروع وصفحاته

يتضمن المشروع **كافة صفحات المتجر الإلكتروني الحديث** بتصميم أسطوري داكن مستوحى من فضاء ونجوم شعار الدار:

1. **الصفحة الرئيسية (Home Page)**:
   - قسم البداية الفلكي (Hero) مع حلقات مدارية متحركة وتأثيرات ضوئية فاخرة.
   - شريط مميزات المتجر (شحن مبرد مجاني، أصالة 100%، عينات مجانية، ضمان ذهبي).
   - قسم الأكثر طلباً ومبيعاً (Best Sellers) مع إمكانية الإضافة السريعة للسلة.
   - بانر العرض الكوني الحصري مع عداد تنازلي حي (Live Countdown Timer).
   - استعراض المجموعات العطرية (المدار الشرقي والعود، سديم الفانيليا، إصدارات النيش).
   - دعوة تفاعلية لاختبار العطور الفلكي (Perfume Quiz Teaser).
   - حائط تقييمات وتجارب العملاء الحقيقيين.

2. **المتجر والكتالوج (Shop / Catalog)**:
   - تصنيفات متقدمة (الكل، الأكثر مبيعاً، رجالي، نسائي، للجنسين، شرقي وعود، عطور النيش).
   - تصفية حسب العائلة العطرية (خشبي، زهري، عنبري، جلدي مدخن، سويتي، بحري).
   - شريط منزلق لتحديد نطاق السعر (Price Slider).
   - ترتيب المنتجات (الأكثر شعبية، الأعلى تقييماً، السعر من الأقل للأعلى، الأحدث).
   - بحث فوري لحظي في الكتالوج.

3. **تفاصيل العطر (Product Details)**:
   - معرض صور عالي الدقة مع تكبير وتغيير الصور المصغرة.
   - مخطط **الهرم العطري التفاعلي** (الافتتاحية Top Notes، قلب العطر Heart Notes، قاعدة العطر Base Notes).
   - اختيار سعة الزجاجة (50ml / 100ml / 200ml) مع تحديث فوري للسعر.
   - عداد الكمية وأزرار "أضف إلى السلة" و "شراء فوري مباشر".
   - زر إضافة العطر للمفضلة (Wishlist).
   - علامات الضمان والتركيز (Extrait de Parfum 35%) ودرجة الثبات والفوحان.
   - تبويبات تفاعلية للمواصفات وآراء العملاء مع إمكانية إضافة تقييم جديد.
   - قسم "عطور كوكبية مشابهة".

4. **سلة المشتريات (Cart Page & Drawer)**:
   - درج سلة منزلق جانبي سريع (Quick Slide-over Drawer) متاح من كل الصفحات + صفحة سلة مخصصة.
   - شريط تفاعلي لحساب الشحن المجاني (شحن مجاني عند الشراء بـ 350 ر.س).
   - تطبيق كوبونات الخصم (`KOON10` لخصم 10%، `VIP20` لخصم 20%).
   - اختيار **العينة الفاخرة المجانية** المرفقة مع الطلب.
   - خيار **التغليف الملكي للهدايا** مع كتابة رسالة إهداء شخصية.

5. **إتمام الطلب والدفع (Checkout)**:
   - إدخال بيانات التوصيل لجميع مدن المملكة العربية السعودية.
   - اختيار سرعة الشحن (شحن قياسي مبرد 2-4 أيام أو شحن فوري خلال 24 ساعة).
   - طرق دفع متكاملة:
     - **مدى Mada**
     - **Apple Pay**
     - **Visa / Mastercard**
     - **تمارا Tamara** (تقسيط 4 دفعات)
     - **تابي Tabby** (تقسيط 4 دفعات)
     - **الدفع عند الاستلام (COD)**
   - معالجة دفع تفاعلية آمنة.

6. **تأكيد الطلب والفاتورة (Order Confirmation)**:
   - احتفال كوني بتأكيد الطلب مع تأثير Confetti.
   - رقم طلب فريد قابل للتتبع (مثال: `KOON-892415`).
   - خط زمني تفاعلي لحالة الطلب (تم الاستلام -> جاري التجهيز والتعتيق -> خرج للتوصيل -> تم التسليم).
   - فاتورة إلكترونية مفصلة قابلة للطباعة المباشرة (`Print Invoice`).

7. **مستكشف العطور الكوني (Interactive Perfume Quiz)**:
   - اختبار ذكي من 4 أسئلة يحلل تفضيلاتك العطرية ويقترح العطر الأنسب لشخصيتك مع خصم فوري.

8. **تتبع الشحنة المباشر (Track Order)**:
   - إمكانية تتبع أي شحنة برقم الطلب مع عرض شركة الشحن المبردة والموعد المتوقع للتسليم.

9. **قائمة الرغبات (Wishlist)**:
   - حفظ العطور المفضلة وإمكانية نقلها جميعاً إلى السلة بضغطة زر.

10. **عن كون بيرفيوم (About Us)**:
    - قصة تأسيس الدار، وفلسفة الشعار، ومعايير انتقاء المكونات والتعتيق البطيء.

11. **اتصل بنا (Contact Us)**:
    - نموذج تواصل تفاعلي، زر محادثة واتساب مباشر، وعنوان المعرض في الرياض.

12. **الأسئلة الشائعة والسياسات (FAQ & Policies)**:
    - توضيح الضمان الذهبي، طرق حفظ العطور، وسياسة الاسترجاع والشحن.

13. **حسابي (Customer Profile)**:
    - سجل الطلبات السابقة، العناوين المحفوظة، ونقاط الولاء.

## 🚀 طريقة تشغيل المشروع

المشروع جاهز ومبني بالكامل في المجلد الحالي. لتشغيله محلياً:

```bash
# تشغيل خادم التطوير
npm run dev

# أو بناء نسخة الإنتاج وتشغيل المعاينة
npm run build
npm run preview
```

ثم افتح الرابط في المتصفح: `http://localhost:3000` (أو الرابط المعروض في الطرفية).
